# Password Manager

## 📌 Beschreibung / Description

**DE:**  
Dieses Repository enthält das wöchentliche Projekt **Password Manager** aus meinem Kurs am **Syntax Institut**, einem Kurs zur Ausbildung als **App Developer**. Aktuell befinde ich mich im **zweiten Modul: Grundlagen der Programmierung**. Ziel dieses Projekts ist es, fortgeschrittene Konzepte der funktionalen Programmierung mit Swift zu erlernen und praktisch anzuwenden. Das Projekt dient ausschließlich zu Lernzwecken und ist nicht für den produktiven Einsatz gedacht.

**EN:**  
This repository contains the weekly project **Password Manager** from my course at the **Syntax Institut**, a training program to become an **App Developer**. I am currently in **Module 2: Fundamentals of Programming**. The goal of this project is to learn and apply advanced functional programming concepts using Swift. This project is for educational purposes only and not intended for production use.

## 🚀 Technologien / Technologies

- Swift
- Xcode

## 🎓 Gelernte Konzepte / Learned Concepts

- Fortgeschrittene Funktionen (Advanced Functions)
- Closures
- Nutzung von Higher-Order Functions (e.g. `map`, `filter`, `reduce`)
- Eigene Higher-Order Functions schreiben

## 📂 Projektstruktur / Project Structure

```
Password Manager/
├── Closures.swift        # Enthält alle erstellten Closures
├── Entry.swift           # Entry-Struct zur Repräsentation einzelner Passworteinträge
├── Vault.swift           # Vault-Klasse mit allen Methoden zur Verwaltung der Einträge
├── main.swift            # Auskommentierte Tests & Aufruf der run()-Methode zur Programmausführung
```

## 📖 Installation & Nutzung / Installation & Usage

**DE:**
1. Repository klonen:
   ```
   sh
   git clone https://github.com/ryliecc/M2-06-PasswordManager.git
   ```
2. Das Projekt in **Xcode** öffnen.
3. Auf den **Play-Button** in Xcode klicken, um das Programm auszuführen.

**EN:**
1. Clone the repository:
   ```
   sh
   git clone https://github.com/ryliecc/M2-06-PasswordManager.git
   ```
2. Open the project in **Xcode**.
3. Click the **Play button** in Xcode to run the program.
